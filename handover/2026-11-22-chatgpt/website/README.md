# PrompTugal OWASP Source Explorer

Static website; no build step or secrets required. Serve `dist/` with any static host (for example `python3 -m http.server 8000 --directory dist`). Open http://localhost:8000.

`dist/app.js`, `dist/style.css` and `dist/index.html` implement the explorer. `dist/data/` holds the captured snapshot, evidenced graph and historical title catalogue. `dist/downloads/` holds the Word handover, Markdown instructions and research collector ZIP. The website source download excludes itself to avoid recursive packaging.

Read the handover before extending the product. Source-specific republication terms, API stability and historical completeness require further verification. Two page bodies support full-text search; the complete archive catalogue supports title search. The collection workflow in the research ZIP is inactive until installed and verified in its destination repository.

Spotify is a documented integration review only. No account access, credentials or personal Spotify data are included. RiskMandate policy definitions and enforcement must be connected by the implementing team.
